# The tasks, and what each one does

> **Generated from `.vscode/tasks.json` by `.github/scripts/task-page.mjs`. Do not edit this file.**
> Change a task and regenerate: `node .github/scripts/task-page.mjs --write`. **C179** compares the
> two and fails the build when they disagree.

**A task is how a person does the half of the process an agent cannot.** On the Copilot surface the
agent holds no terminal, so anything that writes to the run record, signs a gate or runs a check
happens here. An agent may start a task that carries no box; a task that opens one ends the agent's
turn, and that is the mechanism a signature rests on.

**46 tasks.** Every one is in the command palette under its full label, once you choose `Tasks: Run Task` there: the palette does not list task labels on its own.
